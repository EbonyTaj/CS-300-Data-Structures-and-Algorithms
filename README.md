# CS 300 – Data Structures and Algorithms

## Course Overview
This repository contains selected coursework from CS 300 at Southern New Hampshire University. The focus of this course was analyzing and implementing core data structures to solve structured data problems efficiently.

## Project One– Data Structure Analysis
This project includes a comparative analysis of three data structures:
- Vector
- Hash Table
- Binary Search Tree

The analysis evaluates run-time complexity (Big-O) and memory considerations for insertion, search, and traversal operations.

The purpose was to determine which structure best supports efficient storage and retrieval of course data.

## Project Two– ABCU Advising Application
This C++ application loads course data from a file, stores it using the selected data structure, and prints the Computer Science course list in alphanumeric order along with prerequisites.

The implementation reflects the design and performance analysis completed in Project One.

## Reflection
This work strengthened my understanding of how data structure selection impacts performance, scalability, and maintainability. Analyzing complexity before implementation improved my design decisions and reinforced the importance of structured planning in software development.
